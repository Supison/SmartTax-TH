# SmartTax TH 🇹🇭

A web-based Thai personal income tax calculator built with HTML, CSS, and JavaScript.

## 📌 Project Overview

SmartTax TH is a web application designed to estimate personal income tax in Thailand. Users can enter their income and eligible deductions to view estimated taxable income, tax payable, take-home income, and a tax breakdown chart.

## ✨ Features

- Calculate estimated annual personal income tax.
- Enter monthly salary and other income.
- Include personal deductions such as social security, life insurance, and provident fund / RMF / SSF contributions.
- Support child allowance inputs.
- Display estimated tax payable and take-home income.
- Visualize the tax breakdown using a doughnut chart.
- Switch between light and dark themes.
- View a sample frontend and backend architecture.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Chart.js
- Font Awesome

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## ⚠️ Disclaimer

This project is for educational and demonstration purposes. Tax calculations are estimates based on the rules and assumptions implemented in the application. They may not reflect all current Thai Revenue Department regulations or individual circumstances. Please verify the applicable tax rules before using the results for actual tax filing.
